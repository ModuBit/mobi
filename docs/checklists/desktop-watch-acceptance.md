# 远程桌面（迭代 1：纯观看）真机验收 checklist

供每次发版回归。E2E 冒烟（fake-rfb）覆盖协议链路，本 checklist 覆盖**真机**才可验证的部分：macOS 屏幕共享、真实 noVNC 渲染、真实断线。

## 前置条件

- [ ] 被控 Mac 开启「系统设置 → 通用 → 共享 → 屏幕共享」，VNC 观看者已允许
- [ ] cli 所在机器 `~/.mobi/settings.cli.json` 配置 `{"desktop": {"vncPassword": "…"}}`（1-16 位，与屏幕共享设置的 VNC 密码一致）
- [ ] hub / cli / web 均为本版本构建

## 验收路径

### 1. 观看

- [ ] 打开「远程桌面」页，选择被控机器 → 数秒内出现桌面画面，画面随被控端变化
- [ ] Inspector「+」菜单可打开 desktop tab，画面跟随 tab 切换不闪断；切走再切回画面仍在

### 2. 抢占

- [ ] 第二个浏览器 tab 打开同一机器的观看页 → 新 tab 出画面
- [ ] 旧 tab 显示「该机器已在其他设备开始新的观看」，**不自动重连**（不出现画面闪回）

### 3. 主动关闭

- [ ] 侧边栏「远程桌面」分区点击条目 ✕ → 弹确认框 → 确认后该观看页显示「观看流已被关闭（可能从其他设备操作）」，侧边栏分区消失

### 4. 断线恢复

- [ ] 观看中断开被控端网络/杀掉 cli → 观看页出现错误归因
- [ ] 恢复后（重启 cli）刷新或重新选择机器可恢复观看

### 5. 认证失败

- [ ] VNC 密码错误时观看页显示认证失败提示（不无限重试）
- [ ] 未配置密码时给出「未配置」提示

### 6. 断开清理

- [ ] 关闭观看页 → 另一浏览器窗口的侧边栏分区 15s 内消失（streams 列表清空）
