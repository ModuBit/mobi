# Web 词汇表

浏览器前端上下文（会话远程交互界面）。首建于工具卡片改版（Tool Chips）特性。

## Language

### 引用

**引用（Quote）**：
用户消息中对**已落库历史消息某个片段**的指认——`messageId` 指针 + 选中文本快照（excerpt）+ 可选评论。引用是注释工作流的载体：让模型针对具体语句回应，而非复读整条消息。类型按**引用目标**演进（本期仅 message；未来 block/external），不按内容形态分。
_Avoid_: 整条消息引用（本期语义已是片段级）、按内容类型分类（文本引用/图片引用）

**引用评论（Quote Comment）**：
用户对引用内容附加的疑问或澄清（可选），wire 子标签 `<user-comment>`。评论是引用的价值主体——不进 prompt 的评论毫无意义；发送后气泡中随引用可见。
_Avoid_: 注释（与代码注释混淆）、备注

**引用组（Quote Group）**：
发送后气泡中多条引用的合并呈现容器——一个组件内编号 `1.`/`2.`/`3.` 连续展示，条间分隔线。与 composer 侧「引用胶囊」同源异形：胶囊 = 最紧凑（只留数量），组块 = 内容可见（引用是消息内容的一部分，隐藏不诚实）。
_Avoid_: 散落多个独立引用块

**回应批注（Response Annotation）**：
agent 回复正文中的脚注锚点——模型在真正回应某条引用的位置输出内联 directive，客户端渲染为「注释 N」标记，hover 看引用原文与评论、点击定位源消息。是**引用的派生能力**而非独立概念：引用 role 为 agent 的消息时自动生效，无新增交互入口；引用 user 消息永不产生批注。
_Avoid_: 独立批注功能/入口（它是引用的附带效应）、脚注编号自成一系（与引用编号同源）

### 会话生命周期

**会话恢复（Session Resume）**：
让一个未激活的逻辑会话重新进入可交互状态。恢复结果以 Hub 返回的权威会话 ID 为准：它可能沿用原 ID，也可能因恢复过程中产生新的活跃记录而改变；这两条记录属于同一逻辑会话，不是与其他会话合并。
_Avoid_: 重启会话（容易误解为丢弃原上下文新建）、合并到其他会话

### 聊天流 · 工具呈现

**工具行（Tool Row）**：
agent 单次工具调用在聊天流中的单行呈现——动词 + 摘要 + 尾随信息。行本体的点击语义是「展开/收起详情」。
_Avoid_: 工具卡片标题、tool chip 行

**文件 Chip（File Chip）**：
工具行中承载文件路径的 mono 字体元素。Chip 的点击语义是「打开文件」（mobi://file/open），与行本体的展开详情物理分离。带 hover 描边的 chip 才可点击；非文件路径的 command/pattern 用同款形态纯展示，不暗示可点。
_Avoid_: 路径链接、badge

**跳转类工具（File-bearing Tools）**：
输入中天然携带文件路径的工具（Read / Edit / MultiEdit / Write）——文件 Chip 可点击的资格集合。样式语言全量统一，点击资格按工具判定。
_Avoid_: 白名单

**文件工具目标（File Tool Target）**：
跳转类工具输入中表示目标文件的原始路径。兼容 `file_path` / `path` / `file`，按此顺序取首个非空字符串；兼容解释由 `getFileToolTarget()` 集中负责，工具行、折叠组和旧版工具标题只决定各自的展示与计数规则。
_Avoid_: 在调用方重复罗列路径字段

**diff 统计（Diff Stat）**：
编辑类工具行尾随的增删行数（+12 −3），由输入内容静态推算，非服务端权威值。
_Avoid_: 变更数、diff count

**权限面板（Permission Panel）**：
工具待审批时的请求呈现区。其中的文件路径同样以文件 Chip 呈现——审批前可先看文件再决策。

**折叠组（Tool Call Group）**：
聊天流中连续可折叠块（可折叠工具 + thinking）的聚合呈现。成组只看「连续同类块 ≥ 2」，与执行状态无关——运行中、待审批、已落定均可进组；单个可折叠块不成组，保持散落。组头是组的单一摘要面：有活跃块时展示最新活跃项的实时动态（如「正在编辑 src/a.ts」），全部落定后展示汇总统计（如「编辑了 3 个文件 · 1 个失败」）。
_Avoid_: 归档组、完成组（成组不以落定为前提）

**活跃块（Active Block）**：
组内仍在执行的可折叠块（运行中/待审批的工具、正在进行的 thinking）。组头在任一活跃块存在期间以「最新活跃项」为动态标题，活跃块全部落定后标题切回汇总形态。
_Avoid_: 运行中块与待审批块的混称（二者皆是活跃块）

### 画板

**草图（Sketch）**：
用户在画板中手绘的单文件产物——内嵌可编辑场景数据的 PNG（`.excalidraw.png`）。图片本身可直接预览/发送给模型，场景数据可被画板重新载入继续编辑；二者是同一文件的两个可读面，不存在伴随的独立数据文件。
_Avoid_: 白板文件、双文件方案（json+png 分离）

**草图标记（Sketch Mark）**：
image block / 附件 / 草稿引用上的可选 `sketch: { format }` 协议字段，声明「该图是草图、可重编辑」及其引擎格式。重编辑入口（附件卡角标、气泡 hover 角标）的存在判据；`format` 换画板引擎后仍可识别。
_Avoid_: 用文件扩展名做唯一判据（扩展名只是人类可读的冗余提示）

**重编辑（Sketch Re-edit）**：
从既有草图打开画板继续编辑的行为。composer 附件重编辑是**替换**（新产物顶替旧附件，旧服务器文件保留）；气泡重编辑是**追加**（产物落回 composer 作为新消息素材，历史消息不可变）。
_Avoid_: 原地编辑历史消息

**画板载体（Sketch Host）**：
承载画布的 Drawer 容器形态：移动端全屏、PC 停靠聊天列（可切全屏）。防误关是载体不变量——mask 点击、ESC、右上角 X 一律关闭路径禁用，唯一出口是画布内显式「完成/取消」。
_Avoid_: MobileDrawer（下拉关闭手势与防误关冲突）
