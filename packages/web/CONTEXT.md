# Web 词汇表

浏览器前端上下文（会话远程交互界面）。首建于工具卡片改版（Tool Chips）特性。

## Language

### 会话生命周期

**会话恢复（Session Resume）**：
让一个未激活的逻辑会话重新进入可交互状态。恢复结果以 Hub 返回的权威会话 ID 为准：它可能沿用原 ID，也可能因恢复过程中产生新的活跃记录而改变；这两条记录属于同一逻辑会话，不是与其他会话合并。
_Avoid_: 重启会话（容易误解为丢弃原上下文新建）、合并到其他会话

### 聊天流 · 工具呈现

**工具行（Tool Row）**：
agent 单次工具调用在聊天流中的单行呈现——动词 + 摘要 + 尾随信息。行本体的点击语义是「展开/收起详情」。
_Avoid_: 工具卡片标题、tool chip 行

**文件 Chip（File Chip）**：
工具行中承载文件路径的 mono 字体元素。Chip 的点击语义是「打开文件」（mobi://file/open），与行本体的展开详情物理分离。带 hover 描边的 chip 才可点击；非文件路径的 command/pattern 用同款形态纯展示，不暗示可点。
_Avoid_: 路径链接、badge

**跳转类工具（File-bearing Tools）**：
输入中天然携带文件路径的工具（Read / Edit / MultiEdit / Write）——文件 Chip 可点击的资格集合。样式语言全量统一，点击资格按工具判定。
_Avoid_: 白名单

**文件工具目标（File Tool Target）**：
跳转类工具输入中表示目标文件的原始路径。兼容 `file_path` / `path` / `file`，按此顺序取首个非空字符串；兼容解释由 `getFileToolTarget()` 集中负责，工具行、折叠组和旧版工具标题只决定各自的展示与计数规则。
_Avoid_: 在调用方重复罗列路径字段

**diff 统计（Diff Stat）**：
编辑类工具行尾随的增删行数（+12 −3），由输入内容静态推算，非服务端权威值。
_Avoid_: 变更数、diff count

**权限面板（Permission Panel）**：
工具待审批时的请求呈现区。其中的文件路径同样以文件 Chip 呈现——审批前可先看文件再决策。

**折叠组（Tool Call Group）**：
聊天流中连续可折叠块（可折叠工具 + thinking）的聚合呈现。成组只看「连续同类块 ≥ 2」，与执行状态无关——运行中、待审批、已落定均可进组；单个可折叠块不成组，保持散落。组头是组的单一摘要面：有活跃块时展示最新活跃项的实时动态（如「正在编辑 src/a.ts」），全部落定后展示汇总统计（如「编辑了 3 个文件 · 1 个失败」）。
_Avoid_: 归档组、完成组（成组不以落定为前提）

**活跃块（Active Block）**：
组内仍在执行的可折叠块（运行中/待审批的工具、正在进行的 thinking）。组头在任一活跃块存在期间以「最新活跃项」为动态标题，活跃块全部落定后标题切回汇总形态。
_Avoid_: 运行中块与待审批块的混称（二者皆是活跃块）
